⑤ 交互流程

核心闭环
① 新建 / 打开笔记→ ② 上预览 / 下编辑（40%·20%·收起）→ ③ 选中一段 → AI 改写→ ④ 流式输出→ ⑤ diff 预览→ ⑥ 接受 / 拒绝（可 Ctrl+Z）→ ⑦ 打标签 / 置顶 / 归档
· 生成类结果（摘要 / 大纲 / 标题 / 标签）走「插入到光标处 · 追加到文末 · 复制」三选一，不进 diff；
· 问答类结果只读，不写回文档（用户可手动「作为附录插入」）；
· 任何写入都先落在编辑器缓冲并入撤销栈，自动保存随后落盘 —— 不存在「AI 直接改文件」；
· AI 边栏可收起成 44px 竖轨（保留「生成中」角标），收起时笔记区横向扩展占回空间。
· 移动端与桌面同一套上下分屏，只是 AI 侧栏换成底部抽屉。
